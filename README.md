# Olist-Store-Analysis
1. Project Title: 
Olist Store Analysis

2. Description:
The Olist Store Analysis the a visually enaging and analytical PowerBI report designed to help users explore and compare 1M+ units across 9 KPI’s including yearly total profit 2.42M, total sales 16.01M & different city wise payment trend analysis. The dataset contains detailed information about e-commerce orders placed through the Olist platform. It includes information about customers, sellers, orders, products, payments, reviews, delivery, and product categories.

3. Tech Stack:
PowerBI Desktop - Main data visualization platform used for report creation.
Power Query - Data transformation and cleaning layer for reshaping and preparing the data.
DAX - Used for calculated measures, dynamic visuals and conditional logic.
File Format- .pbix for development and .png for dashboard preview.

4. Features:
Olist is the E-Commerce platform that connects customers with sellers across different regions.
This project focuses on analyzing Olist e-commerce data to understand key business and customers related insights such as:
  Sales and payment performance across different customers segments.
  Customer purchasing behavior based on payment methods and review scores.
  Customer satisfaction based on review score and delivery/ shipping time.
  City-wise analysis, including customer and payment trends in Sao Paulo.
By using meaningful and visualization tools, the project aims to transform raw e-commerce data into meaningful insights that can better business decisions.
The Olist E-commerce Analytics Dashboard aims to deliver actionable insights from e-commerce data, enabling data-driven business decision. The following core objectives guide the development and implementation of this analytics solution.
